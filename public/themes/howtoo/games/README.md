# Dashboard game card images

Add the game artwork here. Each key uses two PNG files: `1` is the small card icon and `2` is the card background.

| Game | Icon | Background |
| --- | --- | --- |
| Minecraft Java and Bedrock | `Mine1.png` | `Mine2.png` |
| Project Zomboid | `Zomboid1.png` | `Zomboid2.png` |
| ARK | `Ark1.png` | `Ark2.png` |
| Terraria | `Terraria1.png` | `Terraria2.png` |
| Counter-Strike 2 | `CS1.png` | `CS2.png` |
| Fallback | `Default1.png` | `Default2.png` |

Missing files are handled in the dashboard with a visible `NO Image` placeholder.
